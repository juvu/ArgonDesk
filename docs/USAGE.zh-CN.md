## 0.4.2 做了什么

ArgonDesk 是本地文件的保存与读取连接，无需模型先研究这个软件。简短的 MCP 指导会说明执行方式，要求保留细节、真实动画和交互。

简单的新建文件可以这样完成：

1. 查询一次 workspace_info，复用返回的 workspace_id。
2. 用 write_file 的 mode=create 整份保存成品。
3. 报告路径；任务确实需要时再检查。

create 模式拒绝覆盖已有文件，自动创建缺失的父目录，不必仅为防重名先列目录。修改已有工程仍需读取相关上下文，不能为了省调用跳过必要检查。

成功结果只保留 content[0].text 中一份 JSON，不再通过 structuredContent 重复发送正文。本地同一份 24,447 字节样例，读取结果从 60,917 字节降到 33,384 字节，约减少 45.2%。工具定义仍约 4 KB，另有 685 字节启动指导。**这不是模型 token 或 Google 额度的节省比例**；客户端决定实际向模型传入哪些内容。

Task 规划、模型内部推理、客户端缓存和计量不由工作台控制，模型也可能不遵循指导。本次没有向 Gemini 额外发送验收提示词，不声称已实测降低 Google 额度，或已证明模型创作质量提升。

## 怎样得到真正的动效

文件工具按原文保存，不会自动把静态插画变成动画。“小猫弹吉他”也可能只被模型理解为一个姿势，可以明确要求：

> 在当前工作区创建细节丰富、可离线打开并真正循环播放动画的太空猫弹吉他 SVG，保存为 space-cat-animated.svg。必须实现拨弦手臂、琴弦、尾巴和星光的实际动画，不能只画静态姿势。查询一次工作区后整份写入，按需检查相关文件。完成后说明路径与实现的动画；没有实际渲染测试就明确说明。

新工具指导对动作场景优先建议动画，用户明确要求静态时尊重静态。这属于模型指令，不是后端动画生成器或效果保证。写入成功只能证明保存成功，还需打开成品检查播放。

如果只是独立创作插画、不依赖已有本地内容，普通 Chat 生成后下载可以省去 Task 工具轮次。需要持续读写和修改本地工程时，再使用 ArgonDesk。

## 思考等级

Google 的[模型说明](https://support.google.com/gemini/answer/18648722?hl=en)写明：没有选择等级时默认 Low。本机在 2026-10-16 看到的 Task 菜单只有 Flash 和 Argon，没有等级选择；不能因此推断它的实际内部思考预算。文件工具无法读取或设定这个参数，以自己的官网界面为准。

## 五小时与每周额度

Google 官方说明使用[按计算量计量的限制](https://support.google.com/gemini/answer/16275805?hl=en)，受提示复杂度、模型/功能和上下文长度影响。五小时与每周上限的分母不同，可能五小时用满、每周还剩很多；周余额不能顶替五小时上限。

Chat 用 17%、Task 用 27% 不是严格对照实验：生成长度、模型、思考、上下文和工具轮次都可能不同。工作台的请求数、字节数不能换算成这些百分比，也不能重置或转移额度。

## 自动启用与更新

“偏好设置 → 启动时自动启用文件工具”会在每次后台启动时恢复选定目录及保存权限，默认关闭。目录失效或被替换时保持暂停。换目录或权限会立即暂停，但开启此项后重启可以启用新选定目录；手动暂停只对本次运行有效。想继续保留启动暂停，请关闭该项。

更新后刷新工作台，在 Gemini 新开任务。如果 Google 缓存的旧工具定义没有 mode=create，再按官网可用的控件刷新自定义应用。私人连接 URL 不变，不需要长篇 Insert，官网人工 Allow 仍然保留。
