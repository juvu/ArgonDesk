# 验证状态与路线图

[English](ROADMAP.md)

## 当前预览版

已实现六项限定目录的文本工具、只读/编辑、暂停与编号更新、路径及链接限制、原生 MCP JSON 返回、ngrok 进程管理、重连状态、双语界面/托盘、历史与批量替换。

0.4.2 增加可选的启动自动启用、不覆盖的新建与父目录创建、精简模型指导及单份结果。隔离测试覆盖 27 项文件/MCP 检查和 7 种启动场景。响应体积测试不发 Gemini 消息，不能据此证明额度或创作质量改善。详见[用量说明](USAGE.zh-CN.md)及[真实 GitHub CI](https://github.com/nexora-dev9/ArgonDesk/actions)。

本机证据包括真实 MCP 隔离样例、公网 ping 和工具发现、此前从 Gemini 官网批准写入并读回，以及使用者确认文件夹弹窗正常。安装包、安装器与界面检查，不等于已在 GitHub CI 或另一台电脑验证。

## 当前限制

仅 Windows x64。没有终端、完整电脑控制、二进制编辑、删除、多工作区并发或 Google 账户绑定 OAuth。官网写入仍需人工确认；集成提供方仅 ngrok。不承诺长期稳定性或所有账号/模型兼容。桌面入口未签名。

## 后续方向

- 在其他 Windows 电脑验证干净安装。
- 纳入并扩大可复现的界面回归脚本。
- 试做 Cloudflare 或稳定 HTTPS 适配，并真正验证 Gemini 行为。
- 优化首次安装与网络诊断，不随之扩大默认文件权限。
- 将账户授权和更强的系统隔离作为独立设计评估。
- 完成原生验证后再考虑签名、安装器与其他平台。

这些是方向，不是交付日期或承诺。先交付功能边界清楚的可用预览，再持续迭代。
